# Contract — Phase 011 effects and React API

**Status: implemented and verified locally** ([evidence](../evidence.md)). Every effect is a frozen `defineEffect` value
(family `scroll-trigger` or `scroll`), attachable with `attachEffect`/`attachPreset` or the React primitives;
nothing registers at import time. Every scroll-family effect accepts `timeline?: ScrollProgress` (a shared
timeline, e.g. a `<ScrollScene>`'s); without it the effect creates and owns a timeline for its element.

## 1 · Scroll Triggers (ST)

| Id   | API                                                                                                     | Writes / behaviour                                                                                                                                                             | Reduced motion       |
| ---- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------- |
| ST01 | `revealOnEnter` · `<RevealOnScroll preset>`                                                             | holds an Entrance preset's start pose below the fold, plays it on enter (Entrance definitions/presets, not copies)                                                             | instant (never held) |
| ST02 | `staggerOnEnter` · `<StaggerOnScroll preset>`                                                           | same for every element child through the E10 `stagger` effect                                                                                                                  | instant              |
| ST03 | `mode: "once" \| "repeat" \| "reverse"` of the trigger state machine (`createScrollTrigger`, ST01/ST02) | once: play once · repeat: re-arm on every leave · reverse: play out on leave-back, in on (re)enter                                                                             | instant              |
| ST04 | `createScrollTrigger` callbacks · `useScrollTrigger`, `useInView`                                       | `onEnter/onLeave/onEnterBack/onLeaveBack/onChange`; React state changes only on transitions                                                                                    | n/a                  |
| ST05 | `inViewProgress` · `<ScrollEffect preset={inViewProgress}>`                                             | `--neshel-view-progress` (0–1) on the element; native or JS driver; `range`                                                                                                    | static (1)           |
| ST06 | `directionHeader`                                                                                       | transform layer `translateY` (−height) hiding on forward scroll past `offset`, showing on backward scroll, at the top and while focus is inside; `data-neshel-header="hidden"` | instant              |
| ST07 | `stuckState`                                                                                            | `data-neshel-stuck` while a sticky element is stuck; `onChange(stuck)`                                                                                                         | n/a                  |
| ST08 | `createSectionSpy` · `useSectionSpy(ids)`                                                               | active section id (last section above the activation line; last section at the end)                                                                                            | n/a                  |
| ST09 | `lazyEffect` · `<ScrollEffect preset={lazyEffect}>`                                                     | attaches any effect/preset only while the element is near the viewport (`trigger: "lazy"`), destroys it when far (`keepAlive: false`)                                          | n/a                  |
| ST10 | `inViewPresets`, `resolveInView`                                                                        | named trigger options: `default`, `eager`, `lazy`, `center`, `half`, `full`, `top`; any `{ rootMargin, threshold }`                                                            | n/a                  |

`InViewInput` = a preset name or `{ rootMargin?: string; threshold?: number | number[]; root?: Element |
null }`.

| Preset    | rootMargin          | threshold |
| --------- | ------------------- | --------- |
| `default` | `0px 0px -10% 0px`  | 0         |
| `eager`   | `0px 0px 25% 0px`   | 0         |
| `lazy`    | `200% 0px 200% 0px` | 0         |
| `center`  | `-45% 0px -45% 0px` | 0         |
| `half`    | `0px`               | 0.5       |
| `full`    | `0px`               | 0.99      |
| `top`     | `0px 0px -85% 0px`  | 0         |

## 2 · Scroll & Parallax (SP)

| Id   | API                                                                                             | Writes                                                                                                                                                   | Driver    | Reduced                    |
| ---- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | -------------------------- |
| SP01 | `depthParallax` · `<ScrollLayer depth>` in `<ScrollScene>`                                      | transform layer `translateY = (p − 0.5) · distance · depth` (`axis: "x"` → `translateX`)                                                                 | JS        | static                     |
| SP02 | `scrubTransform`                                                                                | transform layer and opacity interpolated from `from`/`to` poses (`translateX/Y`, `rotateZ`, `scale`, `opacity`) with an easing                           | JS        | static                     |
| SP03 | `scrollProgress` · `<ScrollProgressBar>`                                                        | `--neshel-scroll-progress` (package bar: `scaleX(var())` in scroll.css)                                                                                  | native/JS | reduced (kept, unsmoothed) |
| SP04 | `<HorizontalScroll>`                                                                            | section `--neshel-hscroll-distance` (px) + track transform layer `translateX = −p · distance`; layout `pinned`/`stacked`/`scroll`                        | JS        | static (stacked)           |
| SP05 | `pinnedScene` · `<ScrollScene length pin>`                                                      | `--neshel-scene-progress` on the section (inherits to the sticky stage); `data-neshel-scene`                                                             | native/JS | static (variable kept)     |
| SP06 | `imageParallax` · `<ParallaxImage>`                                                             | media child transform layer `translateY` ∈ [−amount, amount] + cover `scale`; frame clips                                                                | JS        | static                     |
| SP07 | `zoomOnScroll`                                                                                  | transform layer `scale` from → to over the range                                                                                                         | JS        | static                     |
| SP08 | `scrollColorShift`                                                                              | exclusive channel (default `--neshel-scroll-color`) = `color-mix(in oklab, …)` between colour stops; optional `themes` → `data-neshel-theme` on a target | JS        | instant (stepped)          |
| SP09 | `stickyStack` · `<StickyStack>`                                                                 | `--neshel-stack-index` per child (sticky offsets in scroll.css) + optional covered-card scale layer                                                      | CSS + JS  | static (no scale)          |
| SP10 | `smooth` option of `createScrollProgress` and of every progress effect / `<ScrollScene smooth>` | spring-smoothed progress (008 integrator via the 010 spring rig)                                                                                         | JS        | off (raw progress)         |
| SP11 | `velocitySkew`                                                                                  | transform layer `skewY` (or `skewX`) = clamp(velocity · factor, ±max), spring back to 0                                                                  | JS        | off                        |

Style and attribute ownership (owner review of PR #8): SP04 writes `--neshel-hscroll-distance` through the
section's motion host (exclusive channel), so a consumer's inline value and priority are restored on
unmount and an external edit while mounted becomes the value restored (the engine keeps writing the
measured distance while mounted). SP08's theme writer follows the current target: changing `themeTarget`
restores the previous target's original `data-neshel-theme` before theming the new one, removing `themes`
restores it immediately, and destroy restores the last target.

## 3 · Additive changes to existing contracts

- `TransformLayer` gains optional `skewX`/`skewY` (degrees; summed; emitted after rotations, before scale).
  Compositions without skew are byte-identical (009 tests unchanged).
- `EntranceOptions` gains `hold?: boolean` (while no run plays, keep the start pose; ignored when motion
  is reduced, after `beforeprint`, and never applied by `<Reveal>`) and `playback?: "in" | "out"`
  (`"out"` plays end → start and then holds the start pose). `StaggerOptions` forwards both. Defaults keep
  010 behaviour.
- `effect.ts` families already include `scroll-trigger` and `scroll`; no change.

## 4 · React (`"use client"`; SSR markup is the plain element)

| Export                                                                 | Notes                                                                                                                                                                   |
| ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<ScrollEffect preset>`                                                | `<div>` or `asChild`; presets of the `scroll`/`scroll-trigger` families (lists allowed); inside a `<ScrollScene>` scroll-family effects receive its timeline            |
| `<RevealOnScroll preset options trigger mode>` / `<StaggerOnScroll …>` | ST01/ST02; `asChild`; hydrated visible content is not hidden                                                                                                            |
| `<ScrollScene length pin smooth driver as>`                            | section (`length` in viewport heights, default 3) + sticky stage `div.neshel-scene-stage`; context timeline; `onProgress` not provided on purpose (no render per frame) |
| `<ScrollLayer depth axis distance>`                                    | SP01 on the scene timeline; `asChild`                                                                                                                                   |
| `<ScrollProgressBar source position>`                                  | package-rendered, `aria-hidden` decorative bar                                                                                                                          |
| `<HorizontalScroll layout label>`                                      | SP04; `role="region"` + `aria-label` when labelled; focus management                                                                                                    |
| `<StickyStack offset scaleCovered>`                                    | SP09; `asChild`                                                                                                                                                         |
| `<ParallaxImage amount>`                                               | SP06; frame `<div>` or `asChild`; moves its first element child                                                                                                         |
| `useScrollProgress(ref, options)`                                      | `ScrollProgress` (stable); no React state                                                                                                                               |
| `useScrollScene()`                                                     | nearest scene's `ScrollProgress` or `undefined`                                                                                                                         |
| `useInView(ref, trigger)`                                              | boolean state, changes only on enter/leave                                                                                                                              |
| `useScrollTrigger(ref, options)`                                       | trigger state; callbacks in a ref (no re-subscribe per render)                                                                                                          |
| `useSectionSpy(ids, options)`                                          | active id state, changes only when the section changes                                                                                                                  |
