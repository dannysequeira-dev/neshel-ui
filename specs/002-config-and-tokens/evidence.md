Findings during implementation:

- **Lightning CSS rewrites the layer statement** in consumer builds:
  `@layer neshel.defaults, neshel.config; @layer neshel.defaults {…}` becomes
  `@layer neshel.defaults {…} @layer neshel.config;` (same layer order). The consumer assertion
  is therefore semantic (first-appearance order), not textual (research R16 point 4 confirmed).
- Contrast ratios are displayed rounded **down** to two decimals; `contracts/tokens.md` now shows
  the engine's values (e.g. light `foreground`/`background` 16.35, previously 16.36 rounded).
- Color.js parses `rgb(a b c)` into NaN coordinates instead of throwing; the colour module
  rejects non-finite sRGB coordinates as `invalid-color`.

**Verified in GitHub Actions:** commit `b67af86`, run 42447036221 — 5/5 jobs success (Ubuntu
Node 22/24/26, Windows Node 26, macOS Node 26).
