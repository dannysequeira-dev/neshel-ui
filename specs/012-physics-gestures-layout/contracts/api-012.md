# Contract — Phase 012 effects and APIs

**Status: implemented and verified locally** ([evidence](../evidence.md)). Every definition is created with
`defineEffect` (ADR 0021), attaches through `attachEffect` (`./core`) or the React components below, writes
the consumer's element only through its motion host (ADR 0022) and never declares a CSS transition or
animation on the consumer's element (rule R-1, ADR 0025). Options are validated with the shared validator
(identical errors on server and client). `reducedMotion: "user" | "always" | "never"` on every effect.

## 1 · Physics & Gestures — `@neshel-ui/animations/gestures` (family `physics`)

| Id  | Definition (id)                             | React                                                             | Channels              | Reduced | Alternative (non-gesture)                                     |
| --- | ------------------------------------------- | ----------------------------------------------------------------- | --------------------- | ------- | ------------------------------------------------------------- |
| G01 | `drag` (`physics/drag`)                     | `<Gesture preset={drag}>`                                         | transform (compose)   | instant | arrow keys (focusable), `controls.moveBy`                     |
| G02 | `dragSnap` (`physics/drag-snap`)            | `<Gesture preset={dragSnap}>`                                     | transform             | instant | arrow keys step through snap points, `snapTo(i)`              |
| G03 | `swipeDismiss` (`physics/swipe-dismiss`)    | `<SwipeDismiss onDismiss>`                                        | transform, opacity    | instant | built-in dismiss button, Delete key, `dismiss()`              |
| G04 | `pullToRefresh` (`physics/pull-to-refresh`) | `<PullToRefresh onRefresh>`                                       | transform (indicator) | reduced | built-in refresh button, `refresh()`                          |
| G05 | `springFollow` (`physics/spring-follow`)    | `<Gesture preset={springFollow}>`, `useSpringFollow`              | transform             | instant | n/a (follows a value the consumer controls)                   |
| G06 | `elasticEdge` (`physics/elastic-edge`)      | `<ElasticScroll>`                                                 | transform (content)   | off     | n/a (decorative)                                              |
| G07 | `fling` (`physics/fling`)                   | `<Gesture preset={fling}>`                                        | transform             | instant | arrow keys, `moveBy`, `reset()`                               |
| G08 | `pinchZoom` (`physics/pinch-zoom`)          | `<PinchZoom>` (zoom controls)                                     | transform (media)     | instant | zoom in/out/reset buttons, `+`/`-`/`0` keys, `zoomBy`         |
| G09 | `rotateGesture` (`physics/rotate`)          | `<Gesture preset={rotateGesture}>`                                | transform             | instant | `[`/`]` keys, `rotateBy`, `reset()`                           |
| G10 | `reorder` (`physics/reorder`)               | `<Reorder>`, `<ReorderItem>`, `<ReorderHandle>`, `useReorderItem` | transform (items)     | instant | handle keyboard (Space, arrows, Escape), move up/down helpers |
| G11 | `squashStretch` (`physics/squash-stretch`)  | `<Gesture preset={[drag, squashStretch]}>`                        | transform             | off     | n/a (decorative)                                              |

Common gesture options: `axis`, `threshold`, `pointerTypes` (default mouse, pen, touch), `disabled`,
`controls` (from `createGestureControls`), callbacks `onStart`/`onEnd` (+ effect-specific). Callbacks never
run per frame unless named `onMove`/`onChange` (documented: not for React state).

- **G01 `drag`** — `inertia` (default true; decay options `power`, `timeConstant`), `constraints` (rect |
  `"parent"` | element), `elastic` (0–1, default 0.35 rubber band), `keyboardStep` px (default 10; Shift ×5),
  `onEnd({ x, y })`.
- **G02 `dragSnap`** — G01 options plus `snap`: array of `{ x?, y? }` points or `{ grid: { x?, y? } }`;
  `constraints` default `"parent"`; release springs to the point nearest the projected rest position;
  `onSnap(index)`.
- **G03 `swipeDismiss`** — `direction` (`"x"` both ways, `"left"`, `"right"`, `"y"`, `"up"`, `"down"`),
  `distance` (fraction of the width, default 0.5), `velocity` px/s (default 800), `onDismiss(direction)`;
  below the thresholds it springs back with resistance; above, it flies out and fades, then calls
  `onDismiss`. The consumer removes the element (presence-friendly).
- **G04 `pullToRefresh`** — attaches to a scroll container (`<PullToRefresh>` renders it): `threshold` px
  (default 72), `onRefresh(): Promise | void`; pulling at the top translates the package-rendered
  indicator (rubber band); release beyond the threshold calls `onRefresh` once and keeps a busy state
  (`aria-busy`) until it settles; never prevents scrolling (research R3).
- **G05 `springFollow`** — follows motion values `x`, `y`, `scale`, `rotate` (MotionValue) with a spring;
  `useSpringFollow(source, spring)` returns a following MotionValue. One spring rig, no React render.
- **G06 `elasticEdge`** — on a scroll container: wheel or touch beyond the start/end translates the
  content element (`content`, default first child) with a rubber band and springs back; passive only.
- **G07 `fling`** — free throw: decay with `bounce` restitution (0–1, default 0.5) against `constraints`
  (default `"parent"`); `onRest({ x, y })`.
- **G08 `pinchZoom`** — on the media element inside a frame: `minScale` 1, `maxScale` 4, two-pointer
  pinch about the centroid, one-pointer pan while zoomed (bounded to the frame), double-tap/double-click
  toggles 1 ↔ `doubleTapScale` (2), optional `wheel` (Ctrl/⌘ + wheel or trackpad pinch, opt-in, the only
  place a default is prevented and only over the frame), `onZoomChange(scale)` at gesture end.
- **G09 `rotateGesture`** — two-pointer rotation (`step` snapping in degrees, optional), `onRotateEnd(deg)`.
- **G10 `reorder`** — on a list element: items are its element children with `data-neshel-reorder-item`
  (`<ReorderItem>`), drag starts on `<ReorderHandle>` (any pointer) or on the item (mouse/pen only, when no
  handle); dragged item follows the pointer, siblings shift by the dragged item's size; drop calls
  `onReorder(from, to)` — **the consumer updates its state**, React re-renders the new order (no DOM
  reordering by the package, no state loss); the dropped item settles from its visual position with the
  shared FLIP animator. `axis` (`"y"` default, `"x"`). Live region announcements per committed move.
- **G11 `squashStretch`** — scales along the dominant velocity axis of the element's own drag/fling
  (volume-preserving, `intensity` 0–1 default 0.25, capped at 25 %); decorative.

## 2 · Layout Animations — `@neshel-ui/animations/layout` (family `layout`)

| Id  | Definition / API                        | React                                            | Driver                                  | Reduced |
| --- | --------------------------------------- | ------------------------------------------------ | --------------------------------------- | ------- |
| L01 | `flipMove` (`layout/flip`)              | `<LayoutGroup>`, `<LayoutItem>`, `useLayoutItem` | JS (FLIP animator, spring/tween)        | instant |
| L02 | `autoHeight` (`layout/auto-height`)     | `<AutoHeight>`                                   | measured WAAPI (RO sizes)               | instant |
| L03 | `listItem` (`layout/list-item`)         | `<AnimatedList>`                                 | presence + FLIP                         | fade    |
| L04 | `sharedLayout` (`layout/shared`)        | `<LayoutItem layoutId>`                          | JS (FLIP across elements)               | instant |
| L05 | `gridReflow` (`layout/grid-reflow`)     | `<Reflow>`                                       | JS (RO reflow FLIP)                     | instant |
| L06 | `collapse` (`layout/collapse`)          | `<Collapse open>`                                | CSS `interpolate-size` / measured WAAPI | instant |
| L07 | `tabIndicator` (`layout/tab-indicator`) | `<TabIndicator>`                                 | CSS on package indicator                | instant |
| L08 | `createPresence` (engine)               | `<Presence>`, `usePresence`, `useIsPresent`      | presence state machine                  | instant |
| L09 | `crossFade` (`layout/cross-fade`)       | `<CrossFade swapKey>`                            | presence + opacity + L02                | instant |
| L10 | `masonry` (`layout/masonry`)            | `<Masonry>`                                      | grid row spans + RO reflow FLIP         | instant |

- **`transition`** on layout effects: `{ type: "spring", spring }` (default `"gentle"`-like 300/30) or
  `{ type: "tween", duration, easing }`. **`layout`**: `"position"` (default), `"size"`, `"both"`.
- **L01** — items registered in a group animate when an update changes their box; framework-free:
  `createLayoutGroup()` + `attachEffect(el, flipMove, { group })`, `group.snapshot()` before mutating,
  `group.play()` after.
- **L02** — wrapper height follows the inner content's observed height (text growing, async content).
- **L03** — `<AnimatedList as="ul" enter exit>` = `LayoutGroup` + `Presence`; items enter/exit with
  `listItem` (opacity + 4 % scale + 8 px offset, or Entrance presets) and siblings FLIP into place.
- **L04** — an element mounting with a `layoutId` present in the group's last snapshot animates from that
  box (move between containers, selected-item highlight).
- **L05** — children of a grid/flex container animate whenever the container reflows (resize, column
  change, item size change), without React renders.
- **L06** — `open` toggles a package panel between 0 and its content height; `driver: "auto" | "css" |
  "js"`; closed content stays in the DOM (`hidden="until-found"` / `inert`).
- **L07** — `active` (element or index) moves a package-rendered indicator (`translate` + `scale` custom
  properties) with a CSS transition on the indicator only; re-measures on resize/font load (RO).
- **L08** — see [layout-engine.md](layout-engine.md) §7. Props: `enter`, `exit` (Entrance definitions or
  presets, or omitted for the built-in fade), `duration`, `initial`, `onExitComplete`, `focusFallback`.
- **L09** — `swapKey` change cross-fades old and new content stacked in one grid cell while the height
  follows (L02); old content is inert during the swap.
- **L10** — `<Masonry columns gap>`: CSS grid with row spans from observed heights; reflows (column count
  change via CSS, image load) animate with L05's engine.

## 3 · Hover H11 and Press P11

| Id  | Definition                                 | React                     | Channels / driver                           | Reduced |
| --- | ------------------------------------------ | ------------------------- | ------------------------------------------- | ------- |
| H11 | `cursorFollower` (`hover/cursor-follower`) | `<CursorFollower>`        | package follower layer, spring via its host | off     |
| P11 | `longPress` (`press/long-press`)           | `<LongPress onLongPress>` | package progress layer, WAAPI               | reduced |

- **H11** — a decorative, `aria-hidden`, `pointer-events: none` follower inside the area; spring follow
  of the pointer (box measured on enter, no read per move); hidden on leave; only for `mouse`/`pen` and
  `(pointer: fine)`; off for reduced motion (live). Options `size`, `spring`, `blend`.
- **P11** — hold for `duration` (default 600 ms) to call `onLongPress` once; progress layer fills; early
  release reverses it; `moveTolerance` (10 px), `pointercancel`, `lostpointercapture`, blur, hidden page
  cancel; the click that follows a completed long press is swallowed (research R12); keyboard: holding
  Space/Enter for `duration` activates (`keyboard: "hold"`, default) or a single press activates
  (`keyboard: "press"`).
