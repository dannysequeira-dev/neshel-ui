# Neshel-UI starter — Vite + Tailwind CSS v4

React 19, Vite 8, Tailwind CSS v4, TypeScript and Neshel-UI with a custom theme generated by the
`neshel` CLI.

```bash
pnpm install   # or npm install / yarn
pnpm dev
```

- `neshel.config.ts` — your colours and radius; `pnpm dev` and `pnpm build` run `neshel generate`.
- `src/index.css` — the canonical import order: Tailwind → Neshel stylesheets → generated file.
- `pnpm check:theme` — fails when the generated stylesheet is stale or a colour pair lacks contrast.

The `@neshel-ui/*` dependencies resolve from npm once version 0.1.0 is published. Before that,
see "Starters" in the documentation for installing local tarballs.

Documentation: https://github.com/dannysequeira-dev/neshel-ui
