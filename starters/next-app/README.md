# Neshel-UI starter — Next.js App Router

Next.js 16 (App Router), React 19, Tailwind CSS v4, TypeScript and Neshel-UI with custom breakpoints
(`phone … wide`, replace mode) and a named theme (`harbor`), generated by the `neshel` CLI.

```bash
pnpm install   # or npm install / yarn
pnpm dev
```

- `app/page.tsx` is a **Server Component**: layout, typography, Button and Card render on the server;
  Dialog and Select are client components inside the package.
- `app/layout.tsx` reads the theme from a cookie, so there is no flash of the wrong theme.
- `neshel.config.ts` — breakpoints and themes; `pnpm dev` / `pnpm build` run `neshel generate`
  (writes `app/neshel.generated.css` and `neshel.generated.d.ts`).

The `@neshel-ui/*` dependencies resolve from npm once version 0.1.0 is published. Before that,
see "Starters" in the documentation for installing local tarballs.

Documentation: https://github.com/dannysequeira-dev/neshel-ui
