## `BreakpointRegistry` and `BreakpointName`

`BreakpointName` is the union of names accepted by responsive props (besides `base`). It is derived
from the augmentable `BreakpointRegistry` interface: empty by default (so the defaults
`sm md lg xl 2xl` apply), augmented by the declarations that `neshel generate` writes:

```ts title="neshel.generated.d.ts" no-check="module augmentation shown verbatim; it would change breakpoint types for every other snippet"
export {};
declare module "@neshel-ui/config" {
  interface BreakpointRegistry {
    readonly names: "phone" | "tablet" | "sm" | "md" | "lg" | "xl" | "2xl";
  }
}
```
