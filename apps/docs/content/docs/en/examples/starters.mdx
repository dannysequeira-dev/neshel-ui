Three starter projects live in the repository's [`starters/`](https://github.com/dannysequeira-dev/neshel-ui/tree/main/starters)
directory. Each is a complete application with real configuration — no monorepo aliases — that
installs `@neshel-ui/*@^0.1.0` from npm. Neshel-UI's CI builds them from the packed packages
(`pnpm check:starters`), and the published 0.1.0 packages were verified by installing each ZIP from
the npm registry and building it (`pnpm check:starters --from-registry`).

| Starter          | Stack                                              | Shows                                             |
| ---------------- | -------------------------------------------------- | ------------------------------------------------- |
| `vite-tailwind`  | React 19, Vite 8, Tailwind CSS v4, TypeScript      | Tailwind integration, components, theme switch    |
| `vite-css`       | React 19, Vite 8, plain CSS, TypeScript            | No Tailwind at all                                |
| `next-app`       | Next.js 16 App Router, Tailwind CSS v4, TypeScript | Server Components, custom breakpoints and theme   |

## Download

<StarterDownloads />

Unzip the archive, then install and start it:

```bash
cd vite-tailwind
pnpm install
pnpm dev
```

npm (`npm install`, `npm run dev`) and Yarn work too. The archives contain no lockfile, so the
first install resolves the latest compatible versions.

## Copy from the repository

Alternatively, copy a starter directory out of a clone of the repository:

```bash
git clone --depth 1 https://github.com/dannysequeira-dev/neshel-ui.git
cp -r neshel-ui/starters/vite-tailwind my-app
cd my-app
```

On Windows PowerShell use `Copy-Item -Recurse neshel-ui/starters/vite-tailwind my-app`. Then run
`pnpm install` and `pnpm dev` in `my-app`.

### Against unreleased changes

To try a starter with the repository's current, unpublished sources, build and pack the packages in
the clone and point the starter at the tarballs:

```bash
cd neshel-ui
pnpm install --frozen-lockfile
pnpm build:packages
node scripts/pack-local.mjs --out ../neshel-tarballs
cd ../my-app
node ../neshel-ui/scripts/pack-local.mjs --use ../neshel-tarballs
pnpm install
```

`--use` rewrites the starter's `@neshel-ui/*` dependencies to `file:` tarball paths.
