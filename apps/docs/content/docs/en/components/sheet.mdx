## Purpose

`Sheet` is a modal dialog anchored to an edge of the viewport. It shares Dialog's behaviour; only its
placement differs. ("Drawer" in other libraries.)

## Import

```tsx title="import.tsx"
import {
  Sheet,
  SheetBody,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@neshel-ui/components";
```

## Controlled and uncontrolled

`open` / `defaultOpen` / `onOpenChange`, as Dialog.

## Accessibility and keyboard

Identical to [Dialog](/en/docs/components/dialog/#accessibility): a title is required, focus is
trapped and restored, Escape closes. Swipe gestures are not provided.

## Common mistakes

- Building a mobile navigation drawer by hand: [MobileMenu](/en/docs/components/mobile-menu/) and the
  [Sidebar](/en/docs/components/sidebar/) drawer already handle closing after navigation.
