## Purpose

`Input` is a styled native `<input>`. Every native attribute works: `type`, `name`, `autoComplete`,
`required`, `pattern`, `list`, …

## Import

```tsx title="import.tsx"
import { Input } from "@neshel-ui/components";
```

## API

<ApiTable package="components" name="InputProps" />

- `uiSize` (`sm md lg`) is the visual size; the native numeric `size` attribute keeps its HTML meaning.
- `invalid` sets `aria-invalid="true"` unless you pass `aria-invalid` yourself.

## Controlled and uncontrolled

React's native rules apply: `defaultValue` (uncontrolled) or `value` + `onChange` (controlled).

## Accessibility

Always label the input (`<Label htmlFor>`, `aria-label` or `aria-labelledby`). Reference hints and
errors with `aria-describedby`. Use the right `type` and `autoComplete` so browsers and assistive
technology can help users.

## Common mistakes

- Using `size="lg"` for styling: that sets the native character width. Use `uiSize`.
- A placeholder instead of a label.
