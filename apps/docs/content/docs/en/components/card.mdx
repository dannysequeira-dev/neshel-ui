## Purpose

`Card` groups related content on a surface. Its parts are context-free and composable; use only the
ones you need.

## Import

```tsx title="import.tsx"
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@neshel-ui/components";
```

## Accessibility

- Choose `CardTitle`'s level (`as`) from the page outline.
- For a card in a list of articles, use `as="article"` and `aria-labelledby` pointing to the title.
- Cards are not interactive: put buttons or links inside; never wrap a whole card in a link or button.

## Common mistakes

- Making the entire card clickable with `onClick`: keyboard and screen-reader users cannot discover it.
- Several `CardTitle`s with the default `h3` breaking the heading outline.
