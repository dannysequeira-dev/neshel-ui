## Purpose

`VisuallyHidden` hides content visually while keeping it available to screen readers — extra
context for icons, counts or abbreviated text.

## Import

```tsx title="import.tsx"
import { VisuallyHidden } from "@neshel-ui/components";
```

## Accessibility

Hidden content is still read and still focusable if it contains focusable elements. Do not hide
interactive controls with it. For an icon-only button, an `aria-label` is usually simpler.

## Common mistakes

- Using it to hide content from everyone: use `hidden` or `display: none` instead.
