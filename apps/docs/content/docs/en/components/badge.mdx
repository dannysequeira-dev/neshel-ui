## Purpose

`Badge` labels a status or category with a short text. It renders a non-interactive `<span>`.

## Import

## Accessibility

A Badge has no role and is read as text in context. Do not rely on colour alone: the text itself must
say "Failed", "Active", etc. For a changing status, announce it with a live region.

## Styling

`success`, `warning`, `destructive` and `accent` use the corresponding colour roles (with their
paired foregrounds), so custom themes keep contrast.

## Common mistakes

- Making badges interactive: use a `Button` with `size="sm"` instead.
