## Purpose

`Accordion` groups related sections (an FAQ, settings groups) behind headers. Each header is a real
heading that wraps a button; activating it shows or hides its section.

## Import

```tsx title="import.tsx"
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@neshel-ui/components";
```

`AccordionProps` is the union of the single and multiple props.

## Controlled and uncontrolled

- `type="single"` (default): `value` / `defaultValue` are a string or `null`; `onValueChange`
  receives the open value or `null`. Without `collapsible`, activating the open header keeps it
  open.
- `type="multiple"`: `value` / `defaultValue` are string arrays; `onValueChange` receives the list.

<Preview demo="components/accordion-multiple" />

## Composition

`AccordionTrigger` accepts `asChild` with a child that renders a button. Accordions can be nested: the
arrow keys of each one move only among its own headers.

## Styling

Rules read `--neshel-border`, `--neshel-foreground`, `--neshel-primary` and `--neshel-focus`. The height
transition (200 ms) is optional CSS on the panel; it is removed under reduced motion.

## Errors

An unknown `type`, a `headingLevel` outside 2–6, an empty item `value` or an invalid `asChild` child
throws `NeshelComponentsError` on the server and the client.

## Accessibility

- Headers are headings (`headingLevel`, default 3) containing a native button with
  `aria-expanded` and `aria-controls`; panels are labelled by their header.
- Disabled items cannot be toggled and are skipped by arrow navigation.
- `keepMounted` keeps closed panels in the DOM (hidden); `hiddenUntilFound` lets the browser's
  in-page search open them.
- The optional height transition stops under `prefers-reduced-motion`.

## Keyboard

| Key                   | Action                                      |
| --------------------- | ------------------------------------------- |
| Enter / Space         | Toggle the focused section                  |
| ArrowDown / ArrowUp   | Move to the next / previous header (wraps)  |
| Home / End            | Move to the first / last header             |
| Tab                   | Move to the next focusable element          |

## Common mistakes

- Putting the only copy of essential content in a closed section — keep critical information
  visible.
- Choosing a heading level that skips the page outline — set `headingLevel`.

## Limitations

- Closed content is not in the DOM by default: in-page search and anchors cannot reach it unless you use
  `keepMounted` or `hiddenUntilFound`.
- There is no horizontal orientation.
