## Supported versions

| Requirement   | Supported                                                                                     |
| ------------- | --------------------------------------------------------------------------------------------- |
| React         | `react` and `react-dom` **19** (peer dependencies `^19.0.0`). React 18 is not supported.      |
| Node.js       | Any version your bundler supports for the React packages. The CLI requires Node **≥ 22.13**. |
| TypeScript    | Optional. Declarations are tested with TypeScript 5.9, `moduleResolution` `Bundler` and `NodeNext`. |
| Module format | ESM only (`"type": "module"` packages, `exports` with `types` first). No CommonJS build.     |
| Tailwind CSS  | Optional. Tested with Tailwind CSS v4 (`@tailwindcss/vite`, `@tailwindcss/postcss`).         |
| Browsers      | Current Chromium, Firefox and WebKit (Safari) engines; see [Browser support](/en/docs/guides/accessibility/#browser-and-assistive-technology-support). |

The packages are verified with Vite 8 and Next.js 16 (App Router) applications built from the packed
packages, on Linux, Windows and macOS.
