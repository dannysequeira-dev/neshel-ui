## Purpose

`Heading` renders a heading element (`h2` by default) with the display font, `semibold` weight and a
size that follows its level unless you set one. It is trimmed with Capsize.

## Import

```tsx title="import.tsx"
import { Heading } from "@neshel-ui/typography";
```

## Accessibility

Choose `as` from the document outline (one `h1`, no skipped levels), then choose `size` for the
design. Screen-reader users navigate by heading level, not by size.

## Common mistakes

- Using `size` to "make an h3 look like an h1" while also changing the level for looks: keep the
  level semantic.
- Wrapping a Heading in a link: use `asChild` on the link's text or put the link inside the heading.
