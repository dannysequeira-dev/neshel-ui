## Shared props

| Prop       | Values                                                        | Responsive |
| ---------- | ------------------------------------------------------------- | ---------- |
| `size`     | `xs sm base lg xl 2xl 3xl 4xl 5xl 6xl`                        | yes        |
| `weight`   | `light regular medium semibold bold`                          | yes        |
| `align`    | `start center end justify`                                    | yes        |
| `leading`  | `none tight snug normal relaxed loose` (unitless)             | yes        |
| `tone`     | `default muted primary destructive` (contrast-paired)         | no         |
| `family`   | `body display mono`                                           | no         |
| `tracking` | `tight normal wide`                                           | no         |
| `measure`  | `narrow` 45ch, `comfortable` 65ch, `wide` 80ch, `none`        | no         |
| `wrap`     | `wrap nowrap balance pretty`                                  | no         |
| `truncate` | one line with an ellipsis                                     | no         |
| `trim`     | Capsize trimming, default `true` (not on `Text`)              | no         |

Size scale (rem / default leading): xs 0.75/1.5 · sm 0.875/1.5 · base 1/1.5 · lg 1.125/1.5 ·
xl 1.25/1.4 · 2xl 1.5/1.3 · 3xl 1.875/1.25 · 4xl 2.25/1.2 · 5xl 3/1.1 · 6xl 3.75/1.1.

## Semantics first

`as` sets the element, `size` the scale: `<Heading as="h2" size="5xl">` is an `h2`. Levels are never
changed automatically. There is no `Title`, `Subtitle` or `Code` component: use Heading/Paragraph
sizes and `<Text as="code" family="mono">`.

## Errors

Invalid usage throws `NeshelTypographyError` (`[@neshel-ui/typography] <Component>: …`) on the
server and the client — invalid values, malformed breakpoint keys, `as` + `asChild`, an invalid `as`,
invalid `asChild` children, `trim` on `Text`.

```tsx title="detect-error.tsx"
import { NeshelTypographyError } from "@neshel-ui/typography";

export function isTypographyError(error: unknown): boolean {
  return error instanceof NeshelTypographyError;
}
```

## Layout composition

Typography sets `margin: 0` and nothing else; spacing comes from layout gaps. With trimming, a
`Stack space="4"` between a heading and a paragraph is exactly 1rem from baseline to cap height.
See [Typography and Capsize](/en/docs/guides/typography-capsize/).
