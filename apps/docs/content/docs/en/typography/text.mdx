## Purpose

`Text` styles a phrase inside other text — emphasis, inline code, a muted note, a styled link via
`asChild`. It inherits size, font, weight and colour unless you set them, and it is never trimmed.

## Import

```tsx title="import.tsx"
import { Text } from "@neshel-ui/typography";
```

## Common mistakes

- Using `Text as="p"` for paragraphs: use `Paragraph` (trimmed, block spacing).
- Passing `trim` to `Text`: it throws — inline text cannot be trimmed.
