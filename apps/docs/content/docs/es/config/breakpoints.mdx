## `BreakpointRegistry` y `BreakpointName`

`BreakpointName` es la unión de nombres que aceptan las props adaptables (además de `base`). Se deriva
de la interfaz ampliable `BreakpointRegistry`: vacía por defecto (así se aplican los nombres
predeterminados `sm md lg xl 2xl`) y ampliada por las declaraciones que escribe `neshel generate`:

```ts title="neshel.generated.d.ts" no-check="ampliación de módulo mostrada tal cual; cambiaría los tipos de breakpoint de todos los demás fragmentos"
export {};
declare module "@neshel-ui/config" {
  interface BreakpointRegistry {
    readonly names: "phone" | "tablet" | "sm" | "md" | "lg" | "xl" | "2xl";
  }
}
```
