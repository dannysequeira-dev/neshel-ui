## Propósito

`Paragraph` renderiza texto principal (`p`, o `div` cuando el contenido incluye elementos de bloque)
con la fuente `body` en tamaño `base`.

## Importación

```tsx title="import.tsx"
import { Paragraph } from "@neshel-ui/typography";
```

## Accesibilidad

Usa `measure` (`comfortable` ≈ 65 caracteres) en textos largos: las líneas largas cuestan más de leer.
Evita `truncate` en información esencial: el texto truncado solo está completo para quien puede verlo
por otros medios.

## Errores habituales

- Poner un `div` o una lista dentro de `<Paragraph>` (un `p`): usa `as="div"`.
- Fijar `line-height` con una clase de utilidad: usa `leading` para que el recorte siga siendo exacto.
