Este tutorial crea una aplicación nueva con React 19, Vite y Tailwind CSS v4 y renderiza un Button.
Todos los archivos están completos; cópialos en una carpeta vacía.

## 1. Archivos del proyecto

```json title="package.json"
{
  "name": "my-neshel-app",
  "private": true,
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "tsc --noEmit && vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "@neshel-ui/components": "^0.1.0",
    "@neshel-ui/config": "^0.1.0",
    "@neshel-ui/layout": "^0.1.0",
```

```ts title="vite.config.ts" no-check="Configuración de Vite; pnpm check:starters compila el mismo archivo"
import tailwindcss from "@tailwindcss/vite";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [react(), tailwindcss()],
});
```

```html title="index.html"
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My Neshel app</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```

```css title="src/index.css"
@import "tailwindcss";
@import "@neshel-ui/config/tailwind.css";
@import "@neshel-ui/layout/styles.css";
@import "@neshel-ui/typography/styles.css";
@import "@neshel-ui/components/styles.css";

body {
  margin: 0;
  background: var(--neshel-background);
  color: var(--neshel-foreground);
  font-family: var(--neshel-font-body);
}
```

```tsx title="src/main.tsx"
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import App from "./App";
import "./index.css";

const root = document.getElementById("root");
if (!root) throw new Error("#root not found");

createRoot(root).render(
  <StrictMode>
    <App />
  </StrictMode>,
);
```

```tsx title="src/App.tsx"
import { Button } from "@neshel-ui/components";
import { useState } from "react";

export default function App() {
  const [count, setCount] = useState(0);
  return (
    <main style={{ padding: "2rem" }}>
      <Button onClick={() => setCount((value) => value + 1)}>Clicked {count} times</Button>
    </main>
  );
}
```

Añade el `tsconfig.json` de la página de [TypeScript](/es/docs/getting-started/typescript/).

## 2. Ejecútalo

```bash
pnpm install
pnpm dev
```

Abre la URL que aparece. El botón es un `<button type="button">` nativo con el estilo primario de
Neshel; Tab lo enfoca con un anillo de foco visible, y Enter y Espacio lo activan.

## 3. Prueba las variantes

