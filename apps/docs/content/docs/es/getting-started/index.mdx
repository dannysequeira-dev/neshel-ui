## Versiones compatibles

| Requisito          | Compatibilidad                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| React              | `react` y `react-dom` **19** (dependencias peer `^19.0.0`). React 18 no es compatible.                  |
| Node.js            | Cualquier versión que admita tu empaquetador para los paquetes React. La CLI requiere Node **≥ 22.13**. |
| TypeScript         | Opcional. Las declaraciones se prueban con TypeScript 5.9, `moduleResolution` `Bundler` y `NodeNext`.  |
| Formato de módulos | Solo ESM (paquetes `"type": "module"`, `exports` con `types` primero). No hay compilación CommonJS.     |
| Tailwind CSS       | Opcional. Probado con Tailwind CSS v4 (`@tailwindcss/vite`, `@tailwindcss/postcss`).                    |
| Navegadores        | Motores actuales Chromium, Firefox y WebKit (Safari); consulta [compatibilidad de navegadores](/es/docs/guides/accessibility/#compatibilidad-con-navegadores-y-tecnologías-de-apoyo). |

Los paquetes se verifican con aplicaciones Vite 8 y Next.js 16 (App Router) construidas a partir de
los paquetes empaquetados, en Linux, Windows y macOS.
