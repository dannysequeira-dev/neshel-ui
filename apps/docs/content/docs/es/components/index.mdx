Peers: `react` y `react-dom` 19 y `@neshel-ui/config` (tipos). No hace falta Tailwind, `@source` ni
ningún proveedor. Internamente, las partes interactivas usan Radix (diálogos, sheets, popovers, menús,
menú de navegación, tooltips) y Base UI (Select, MultiSelect, Combobox); tú solo usas la API de Neshel.

## Convenciones

- **Nombres planos**: `DialogContent`, `NavbarBrand` (no `Dialog.Content`), para que las referencias de
  cliente funcionen en React Server Components.
- **`asChild`**: renderiza tu elemento (enlaces, enlaces del router) con los estilos y el comportamiento
  del componente; exactamente un elemento hijo; las clases se unen, los estilos se combinan, los
  manejadores se componen (primero el del hijo) y las refs también.
- **Estado**: los componentes con estado ofrecen `value` / `defaultValue` / `onValueChange` (u `open` /
  `defaultOpen` / `onOpenChange`).
- **Portales**: los contenidos superpuestos aceptan `container`; los temas se copian a través de los
  portales.
- **Props adaptables**: `size` de Button, `breakpoint` de AppShell, `hideBelow` de NavbarNav y
  `breakpoint` de MobileMenu aceptan tus nombres de breakpoint configurados.
- **Iconos**: aporta tus propios nodos React (los ejemplos usan `lucide-react`). Los botones de solo
  icono necesitan `aria-label`.

## Errores

Un uso incorrecto lanza `NeshelComponentsError` durante el renderizado, en el servidor y en el cliente,
con un mensaje que nombra el componente y la solución (por ejemplo `<Button asChild disabled>`: los
enlaces no se pueden deshabilitar).

```tsx title="error-boundary-check.tsx"
import { NeshelComponentsError } from "@neshel-ui/components";

export function describeError(error: unknown): string {
  return error instanceof NeshelComponentsError ? `Neshel usage error: ${error.message}` : String(error);
}
```

## Estilos

Las reglas de los componentes viven en la capa de cascada `components.neshel` y solo leen tokens
semánticos. Sustitúyelas con tokens (lo preferible), propiedades personalizadas de los componentes,
utilidades de Tailwind o tu propio CSS mediante `className`. Consulta
[Temas](/es/docs/guides/theming/#propiedades-personalizadas-de-los-componentes).
