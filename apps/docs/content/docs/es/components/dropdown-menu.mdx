## Propósito

`DropdownMenu` muestra una lista de **comandos** desde un disparador: menús de cuenta, acciones de
fila, desbordamiento de barras de herramientas. Usa la semántica de menú (`menu`, `menuitem`,
`menuitemcheckbox`, `menuitemradio`).

## Importación

```tsx title="import.tsx"
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from "@neshel-ui/components";
```

- Ejecuta los comandos en `onSelect` (teclado y puntero). El menú se cierra tras una selección; llama a
  `event.preventDefault()` en `onSelect` para mantenerlo abierto.
- `DropdownMenuItem variant="destructive"` da estilo a los comandos peligrosos.
- `DropdownMenuShortcut` solo **muestra** un atajo; registra tú la combinación de teclas.

## Controlado y no controlado

Menú: `open` / `defaultOpen` / `onOpenChange`. Elementos de casilla: `checked` / `onCheckedChange`.
Grupos de radio: `value` / `onValueChange`.

## Accesibilidad

El foco entra en el menú al abrirse y vuelve al disparador al cerrarse. Los elementos se anuncian con
su rol y su estado marcado. Las etiquetas (`DropdownMenuLabel`) y los separadores estructuran los menús
largos.

## Teclado

| Tecla                  | Acción                                       |
| ---------------------- | -------------------------------------------- |
| Enter / Espacio / ↓    | Abrir desde el disparador                    |
| ↓ / ↑, Inicio / Fin    | Moverse entre elementos                      |
| Escribir letras        | Saltar a un elemento coincidente             |
| → / ←                  | Abrir / cerrar un submenú                    |
| Enter / Espacio        | Activar el elemento                          |
| Escape                 | Cerrar el menú (primero el más interno)      |

## Errores habituales

- Enlaces de navegación en un DropdownMenu: los usuarios de lectores de pantalla esperan comandos. Usa
  un [NavigationMenu](/es/docs/components/navigation-menu/) o enlaces normales.
- Usar `onClick` en lugar de `onSelect`: se perdería la activación con el teclado.
