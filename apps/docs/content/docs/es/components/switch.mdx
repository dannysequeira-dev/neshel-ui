## Propósito

`Switch` activa o desactiva un ajuste. Úsalo para ajustes binarios inmediatos; usa una casilla de
verificación para opciones que se confirman con un botón de envío en formularios largos.

## Importación

```tsx title="import.tsx"
import { Label, Switch } from "@neshel-ui/components";
```

## Controlado y no controlado

`checked` con `onCheckedChange`, o `defaultChecked`. En un formulario envía `name=value` (`value` es
`"on"` por defecto) solo mientras está activado; `required` impide el envío mientras está
desactivado; al restablecer el formulario vuelve a `defaultChecked` y, como los campos nativos, no llama
a `onCheckedChange`.

## Tamaños y estados

`uiSize` es `sm`, `md` (predeterminado) o `lg`, como los demás campos. `readOnly` conserva el valor y el
foco; `disabled` lo quita del orden de tabulación y de los datos del formulario.

## Accesibilidad

- Un `<button role="switch">` nativo con `aria-checked`; asocia un `<Label htmlFor>` con su `id`
  (hacer clic en la etiqueta lo alterna).
- `invalid` establece `aria-invalid`; describe el error con `aria-describedby`.
- Anillo de foco visible con teclado, colores del sistema en modo de colores forzados y sin
  transición del pulgar con movimiento reducido.

## Teclado

| Tecla           | Acción        |
| --------------- | ------------- |
| Espacio / Enter | Alterna       |
| Tab             | Mueve el foco |

## Errores comunes

- Un interruptor sin etiqueta, o con una etiqueta que cambia según el estado: mantén el nombre y deja que
  `aria-checked` comunique el estado.
- Un interruptor que solo surte efecto al pulsar Guardar: usa una casilla de verificación.
- Esperar `false` en los datos del formulario: apagado no aparece, como una casilla sin marcar.
