## Propósito

`Skeleton` muestra la forma aproximada del contenido mientras se carga.

## Importación

```tsx title="import.tsx"
import { Skeleton } from "@neshel-ui/components";
```

## API

<ApiTable package="components" name="SkeletonProps" />

`width` y `height` aceptan números (píxeles) o longitudes CSS. La animación de pulso se detiene con
`prefers-reduced-motion: reduce`.

## Accesibilidad

Los skeletons son siempre `aria-hidden="true"`. Marca la región que se carga con `aria-busy="true"` y
una etiqueta, y anuncia cuándo termina si es relevante.

## Errores habituales

- Esperar que un skeleton anuncie «cargando»: por diseño es invisible para las tecnologías de apoyo.
