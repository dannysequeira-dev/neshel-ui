## Propósito

`Badge` etiqueta un estado o una categoría con un texto breve. Renderiza un `<span>` no interactivo.

## Importación

```tsx title="import.tsx"
import { Badge } from "@neshel-ui/components";
```

## Accesibilidad

Un Badge no tiene rol y se lee como texto en su contexto. No dependas solo del color: el propio texto
debe decir «Fallido», «Activo», etc. Si el estado cambia, anúncialo con una región *live*.

## Estilos

`success`, `warning`, `destructive` y `accent` usan los roles de color correspondientes (con sus
primeros planos emparejados), así que los temas personalizados conservan el contraste.

## Errores habituales

- Hacer interactivos los badges: usa un `Button` con `size="sm"`.
