## Propósito

`Sheet` es un diálogo modal anclado a un borde de la ventana. Comparte el comportamiento de Dialog;
solo cambia su posición. (En otras bibliotecas se llama «Drawer».)

## Importación

```tsx title="import.tsx"
import {
  Sheet,
  SheetBody,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@neshel-ui/components";
```

## Controlado y no controlado

`open` / `defaultOpen` / `onOpenChange`, como Dialog.

## Accesibilidad y teclado

Idénticos a [Dialog](/es/docs/components/dialog/#accesibilidad): se requiere un título, el foco queda
atrapado y se restaura, y Escape cierra. No incluye gestos de deslizamiento.

## Errores habituales

- Construir a mano un cajón de navegación móvil: [MobileMenu](/es/docs/components/mobile-menu/) y el
  cajón de [Sidebar](/es/docs/components/sidebar/) ya se cierran tras la navegación.
