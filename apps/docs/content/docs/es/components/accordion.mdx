## Propósito

`Accordion` agrupa secciones relacionadas (preguntas frecuentes, grupos de ajustes) tras
encabezados. Cada encabezado es un heading real que contiene un botón; al activarlo se muestra u
oculta su sección.

## Importación

```tsx title="import.tsx"
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@neshel-ui/components";
```

`AccordionProps` es la unión de las props single y multiple.

## Controlado y no controlado

- `type="single"` (predeterminado): `value` / `defaultValue` son un string o `null`;
  `onValueChange` recibe el valor abierto o `null`. Sin `collapsible`, activar el encabezado
  abierto lo mantiene abierto.
- `type="multiple"`: `value` / `defaultValue` son arrays de strings; `onValueChange` recibe la
  lista.

<Preview demo="components/accordion-multiple" />

## Composición

`AccordionTrigger` acepta `asChild` con un hijo que renderice un botón. Los acordeones se pueden anidar:
las flechas de cada uno recorren solo sus propios encabezados.

## Estilos

Las reglas leen `--neshel-border`, `--neshel-foreground`, `--neshel-primary` y `--neshel-focus`. La
transición de altura (200 ms) es CSS opcional del panel y se elimina con movimiento reducido.

## Errores de uso

Un `type` desconocido, un `headingLevel` fuera de 2–6, un `value` vacío o un hijo de `asChild` no válido
lanzan `NeshelComponentsError` en el servidor y en el cliente.

## Accesibilidad

- Los encabezados son headings (`headingLevel`, 3 por defecto) con un botón nativo con
  `aria-expanded` y `aria-controls`; los paneles se etiquetan con su encabezado.
- Los elementos deshabilitados no se pueden alternar y las flechas los saltan.
- `keepMounted` mantiene los paneles cerrados en el DOM (ocultos); `hiddenUntilFound` permite que la
  búsqueda del navegador los abra.
- La transición de altura opcional se detiene con `prefers-reduced-motion`.

## Teclado

| Tecla                 | Acción                                             |
| --------------------- | -------------------------------------------------- |
| Enter / Espacio       | Alterna la sección enfocada                        |
| Flecha abajo / arriba | Pasa al encabezado siguiente / anterior (circular) |
| Inicio / Fin          | Pasa al primer / último encabezado                 |
| Tab                   | Pasa al siguiente elemento enfocable               |

## Errores comunes

- Dejar la única copia de contenido esencial en una sección cerrada: mantén visible la información
  crítica.
- Elegir un nivel de encabezado que rompe la estructura de la página: ajusta `headingLevel`.

## Limitaciones

- El contenido cerrado no está en el DOM por defecto: la búsqueda en la página y los enlaces internos no
  llegan a él salvo con `keepMounted` o `hiddenUntilFound`.
- No hay orientación horizontal.
