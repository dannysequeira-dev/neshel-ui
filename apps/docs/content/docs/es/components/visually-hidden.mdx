## Propósito

`VisuallyHidden` oculta contenido a la vista pero lo mantiene disponible para los lectores de
pantalla: contexto adicional para iconos, contadores o texto abreviado.

## Importación

```tsx title="import.tsx"
import { VisuallyHidden } from "@neshel-ui/components";
```

## Accesibilidad

El contenido oculto se sigue leyendo y sigue siendo enfocable si contiene elementos enfocables. No
ocultes controles interactivos con él. Para un botón de solo icono, un `aria-label` suele ser más
sencillo.

## Errores habituales

- Usarlo para ocultar contenido a todo el mundo: usa `hidden` o `display: none`.
