## Propósito

`Card` agrupa contenido relacionado sobre una superficie. Sus partes no dependen de un contexto y se
pueden combinar; usa solo las que necesites.

## Importación

```tsx title="import.tsx"
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@neshel-ui/components";
```

## Accesibilidad

- Elige el nivel de `CardTitle` (`as`) según el esquema de la página.
- Para una tarjeta dentro de una lista de artículos, usa `as="article"` y `aria-labelledby` apuntando
  al título.
- Las tarjetas no son interactivas: pon botones o enlaces dentro; nunca envuelvas una tarjeta entera
  en un enlace o un botón.

## Errores habituales

- Hacer clicable toda la tarjeta con `onClick`: los usuarios de teclado y de lectores de pantalla no
  pueden descubrirlo.
- Varios `CardTitle` con el `h3` predeterminado que rompen el esquema de encabezados.
