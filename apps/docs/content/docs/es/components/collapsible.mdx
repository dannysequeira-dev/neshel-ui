## Propósito

`Collapsible` revela detalle opcional ("Ver más", filtros avanzados). Es una única divulgación, no
un Accordion de un solo elemento: no tiene heading, grupo ni valor.

## Importación

```tsx title="import.tsx"
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@neshel-ui/components";
```

## Controlado y no controlado

`open`, `defaultOpen` y `onOpenChange`, como Dialog. El contenido cerrado se desmonta salvo que se
use `keepMounted` (oculto) o `hiddenUntilFound`.

<Preview demo="components/collapsible-controlled" />

## Accesibilidad

- El disparador es un botón nativo con `aria-expanded` y `aria-controls`; con `asChild` el hijo
  debe renderizar un botón.
- `disabled` deshabilita el disparador.
- La transición de altura opcional se detiene con `prefers-reduced-motion`.

## Teclado

| Tecla           | Acción                  |
| --------------- | ----------------------- |
| Enter / Espacio | Alterna el contenido    |
| Tab             | Mueve el foco como siempre |

## Limitaciones

El contenido que se desmonta al cerrar pierde su estado (borradores, posición de scroll). Usa `keepMounted`
cuando deba conservarse.

## Errores comunes

- Varios Collapsible como preguntas frecuentes: usa [Accordion](/es/docs/components/accordion/), que añade
  encabezados y flechas.
- Un disparador cuyo texto no dice qué abre.
