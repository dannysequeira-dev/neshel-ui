# Neshel-UI brand assets

**Brand name:** Neshel-UI  
**Tagline:** Rooted in faith. Built with hope.

The official visual is the navy-blue rose with subtle gold reflections and a
soft cross-shaped light in its center. Its symbolic story centers on **faith,
hope, and care**. This is the same generated artwork that was approved for the
project; it has **not been redrawn or regenerated** for this asset pack.

## Files

| File | Use | Notes |
| --- | --- | --- |
| `assets/brand/neshel-ui-logo.png` | README, site, documentation | **Original 1254 × 1254 PNG, byte-identical to the approved artwork.** Includes wordmark and tagline. |
| `assets/brand/neshel-ui-mark.png` | Avatar, social profile, app icon source | Cropped directly from the original image, rose only, no text. |
| `assets/brand/neshel-ui-mark-512.png` | Large square app/profile image | Resized from the original crop. |
| `assets/brand/neshel-ui-mark-256.png` | Small square app/profile image | Resized from the original crop. |
| `assets/brand/neshel-ui-mark-64.png` | Small icon/prototype favicon | Resized from the original crop; check legibility at tiny sizes. |

### Important

- **The full logo is intentionally unchanged.** Keep it as the canonical artwork.
- All images have their original ivory/off-white background. **They are not transparent.**
- The mark variants are crops and resizes of the approved artwork, **not new logo designs**.
- These are raster files (PNG), not vector SVG artwork. Do not represent them as SVG source.
- Avoid recoloring or replacing the light at the center; preserve the navy/gold identity.
- Color values for the eventual design tokens should be specified during Phase 002.
- Before making claims about trademark or licensing of brand assets, decide and document a dedicated policy. The repo's MIT software license is not a substitute for a brand usage policy.

## GitHub README

The repository `README.md` references the canonical file with a relative path:

```html
<img src="assets/brand/neshel-ui-logo.png" alt="Neshel-UI logo" width="390" />
```

GitHub will render that image directly from the repository on both desktop and
mobile without relying on external image hosting.
