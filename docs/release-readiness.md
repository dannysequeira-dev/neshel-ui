## R9 — Phase 004 limitations, assessed

| Limitation                                                            | Assessment for 0.1.0                                                                                                                                                                                                                                                                                 |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unknown well-formed breakpoint keys warn instead of throwing          | **Accepted by design**: the runtime has no configuration (ADR 0010). TypeScript rejects them with generated declarations; documented (custom breakpoints guide, troubleshooting).                                                                                                                    |
| Incomplete Flex runtime validation for some responsive directions     | **Accepted**: exact for static and written directions; documented on the Flex page.                                                                                                                                                                                                                  |
| Approximate Capsize trimming when metrics differ from the loaded font | **Accepted, mitigated**: documented with configuration of real metrics and fallbacks; the docs site and `check:next` load Inter and verify trimming.                                                                                                                                                 |
| Custom-breakpoint consumers must import the generated CSS correctly   | **Mitigated**: one canonical order documented everywhere; verified by consumers, `check:next` and the starters.                                                                                                                                                                                      |
| Browser verification mainly on Chrome                                 | **Resolved**: Firefox and WebKit added (R3). Safari itself is not automated.                                                                                                                                                                                                                         |
| Layout CSS close to its size budget                                   | **Accepted**: 47.7 KiB minified, 3.6 KiB gzip; the existing byte budget and the new gzip budget fail on growth.                                                                                                                                                                                      |
| `@neshel-ui` npm scope unverified                                     | **Open — owner action**: anonymous registry queries (2026-11-08) return 404 for all five package names and for the organisation listing; that shows the names are unused, not that the scope can be owned. The owner must create or confirm the `neshel-ui` organisation (docs/releasing.md step 1). |
