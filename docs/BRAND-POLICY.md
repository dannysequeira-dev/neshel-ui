# Neshel-UI brand asset usage policy

**Status: owner-approved (2026-11-09), in force.** First prepared as a draft in feature 006
(brief §27) and approved by the owner. This policy makes **no trademark claim**: no trademark
registration is asserted or implied.

## What this covers

The name "Neshel-UI", the tagline "Rooted in faith. Built with hope.", the navy-blue rose emblem and
the files in [`assets/brand/`](../assets/brand) ("brand assets"). The software source code is
released under the [MIT license](../LICENSE); this policy does not change it. The MIT license covers
the software only and does not grant rights to the brand assets.

## Software license (unchanged)

Neshel-UI remains MIT-licensed. Redistributing the software, or substantial portions of it, keeps the
existing requirement: include the copyright notice and the MIT permission notice. Nothing in this
policy adds conditions to the use of the software.

## Optional "Built with Neshel-UI" attribution

You **may**, if you wish, show a visual attribution in your application, website or documentation:

- the text "Built with Neshel-UI", **with or without** the original, unmodified rose mark from
  [`assets/brand/`](../assets/brand);
- linking to the official documentation (<https://neshel-ui.vercel.app>) or the official repository
  (<https://github.com/dannysequeira-dev/neshel-ui>).

This attribution is **never mandatory**. Using Neshel-UI does not require any badge, logo, footer
credit or link in your product. Leaving it out is always fine; the only attribution the software
requires is the MIT license notice described above.

When you do use it, keep the mark unmodified (see "Not permitted") and do not word it in a way that
suggests endorsement, sponsorship or affiliation by the project.

## Permitted without asking

- Referring to the project by name in articles, talks, documentation, comparisons and package lists.
- The optional "Built with Neshel-UI" attribution described above.
- Using the unmodified logo or mark to link to the official repository or documentation.
- Stating that your project "uses Neshel-UI" or is "built with Neshel-UI".
- Using the default theme colours in your application (they are part of the MIT-licensed software).

## Please ask first

- Using the logo or mark in your own product branding, website header, merchandise or marketing
  materials beyond the optional attribution above.
- Naming a fork, plugin, theme pack or related package with "Neshel" in its name — prefer a
  descriptive name such as "theme-x-for-neshel-ui" and state that it is unofficial.

## Not permitted

- Modifying, redrawing, recolouring or animating the emblem, or combining it with other marks.
- Presenting the raster logo as vector artwork, or regenerating it with tools.
- Impersonating the official project, its maintainers or its distribution channels.
- Suggesting endorsement, sponsorship or affiliation that does not exist.
- Using the brand assets for content that is hateful, harassing or misleading.

## Forks

Forks are welcome under the MIT license. A fork that is distributed publicly should use its own name
and logo so users can tell it apart from the official project.

## Contact

Questions about brand use: open a GitHub issue in the official repository or contact the
maintainers privately through GitHub.
