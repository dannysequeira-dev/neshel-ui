# ADR 0005 — Adopt Vite 8 for the workspace apps

- Status: Accepted (2026-11-08); locally verified, CI pending
- Date: 2026-11-08
- Relates to: D4 (time-boxed Vite 8 spike), research R20/R21

## Context

The foundation pinned Vite 7.3.7 until the Tailwind and Storybook plugin matrix was
installation-tested with Vite 8. Vite 8 (8.0.0 released 2026-03-12) replaces esbuild/Rollup
with Rolldown and uses Lightning CSS as the default CSS minifier. Vite only builds the
internal apps (Vite playground, Storybook) and the generated external consumer; published
packages are compiled by `tsc` and their CSS is copied, not processed by Vite.

## Decision

Change only the `vite` catalog entry to `^8.3.0` (resolved 8.3.6). Keep
`@vitejs/plugin-react` 5.2.0, whose peer range includes Vite 8; plugin-react 6 requires new
peers and is a separate follow-up. `allowBuilds.esbuild` stays because Storybook 10 still
installs esbuild.

## Evidence (spike on a local branch, Windows 11, Node 26.13.0)

- Peer ranges accept Vite 8: `@tailwindcss/vite` 4.3.5, `@storybook/react-vite` and
  `@storybook/builder-vite` 10.6.6, `@vitejs/plugin-react` 5.2.0. Install succeeds with
  `strict-peer-dependencies=true`; `engines.node` `^20.19.0 || >=22.12.0` fits our floor.
- All gates pass: doctor, lint, typecheck, test, build:packages, check:exports, check:pack,
  check:consumer (React 19.3.1 + TypeScript 5.9.3 + Tailwind 4.3.5 + Vite 8.3.6 from the
  tarball), playground build, Storybook build.
- Playground CSS, Vite 7.3.7 vs 8.3.6: same 78 rules and identical Neshel tokens/utilities.
  Differences come from the Lightning CSS minifier: `--lightningcss-light/dark` polyfill
  variables next to `color-scheme`, a repeated `-webkit-text-decoration:inherit` in the
  preflight `a` rule, and `calc(2.25 / 1.875)` instead of `1.2` (equivalent). Output grows
  from 6,503 to 6,784 bytes (+4.3%). No functional change.
- Storybook prints `DEP0205 module.register() is deprecated` on Node 26 with **both** Vite 7
  and Vite 8, so it is not caused by this change.

## Consequences

- Workspace apps and the external consumer test now exercise Vite 8 only. Vite 7 consumer
  compatibility was CI-verified in run 42435072683 but is no longer re-tested continuously.
- The redundant minified declaration is cosmetic; revisit if Lightning CSS output changes or
  if consumers report issues. `build.cssMinify` can be tuned per app if ever needed.
- Rolling back is a one-line catalog change plus lockfile refresh.

## Alternatives considered

- Keep Vite 7: no blocker found; would defer an unavoidable upgrade.
- Upgrade `@vitejs/plugin-react` to 6 at the same time: broader than the approved spike.
