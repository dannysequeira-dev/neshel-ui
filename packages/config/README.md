# @neshel-ui/config

CSS-first design tokens and typed theme configuration.

**Status:** pre-release, **not published to npm**. Packaging, exports, type declarations and
source maps are validated from the packed tarball (feature 001); the package currently
ships the Phase 001 baseline stylesheet (`@neshel-ui/config/styles.css`) and an empty JavaScript entry. Typed configuration and the final token contract arrive in feature 002.
